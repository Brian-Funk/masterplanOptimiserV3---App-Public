This record describes repository evidence. It is not a legal-title opinion.

The audited Git history uses only the human author-name variants `Brian Funk`
and `brian-funk`; no `Co-authored-by` trailers were found. Third-party packages,
Electron, Chromium, fonts and runtime components are not claimed as
project-owned and are listed in `THIRD-PARTY-NOTICES.md` or their packaged
runtime notices.

Author names and repository control do not by themselves prove copyright
ownership, employment assignment, school rights, permission for copied code or
authority to relicense.
