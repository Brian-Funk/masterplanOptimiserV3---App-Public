# Supported versions

| Release | Security support |
| --- | --- |
| Latest signed Desktop release | Supported |
| Older Desktop releases | Unsupported; upgrade required |
| Development branch or unsigned package | Development use only |

Security fixes are released as a new canonical `vMAJOR.MINOR.PATCH` tag. The
tag, keyless signature identity, signed checksum manifest, and downloaded
package checksum together identify an official Desktop release.

This policy covers the Desktop application. Server support and deployment
requirements are documented in the Server repository and at
[info.mp-opt.net](https://info.mp-opt.net/).
