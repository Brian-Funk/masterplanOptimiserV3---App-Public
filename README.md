<h1 align="center">Masterplan Optimiser - Desktop App</h1>

<p align="center">
  Desktop scheduling and resource-allocation tool for live event organisers.<br>
  Combines constraint-based optimisation with an intuitive calendar interface<br>
  to plan complex multi-day events.
